# Docker PostgreSQL (Deprecated)

> [!NOTE]
> **DEPRECATED**: The Sentinel-X Website backend has migrated to **Neon PostgreSQL** (cloud database).
> Local Docker Desktop PostgreSQL is no longer required or used for website backend development.

If you need to connect the website backend to a database, configure the Neon PostgreSQL environment variables in `apps/website/backend/.env`.

See [`docs/WEBSITE_BACKEND_SETUP.md`](../../docs/WEBSITE_BACKEND_SETUP.md) for full instructions on configuring and running the website backend with Neon PostgreSQL.
